# Agency OS Publisher 0.5.5

Adds authenticated search title and description updates with verified restoration of original wording, including empty overrides that use site defaults. Existing article publishing, category handling and deferred image processing are retained.

The publisher uses WordPress background plugin updates and checks each downloaded package against the SHA-256 in the canonical manifest. Automatic delivery depends on the website allowing WordPress background updates; older installations may need a one-time plugin update.
