# Agency OS Publisher 0.5.8

Adds an authenticated read-only template rehearsal endpoint and four bounded mobile layout repair recipes. Repairs require existing theme-edit permission, save a backup, reject stale state and support guarded restoration. The preview renders an existing published template as a logged-out visitor without creating or changing posts.

Retains official Rank Math score reporting from 0.5.7, checksum-verified native updates, metadata restoration and deferred image processing. No credentials, client data, app source, logs or database files are included.
