# Agency OS Approved Publisher 0.6.1

Corrects native Divi draft previews to use WordPress’s normal frontend rendering lifecycle so Divi generates the page’s actual styles. Preview access requires the existing authenticated WordPress application-password connection and an exact owned-draft job/hash match. Anonymous access is refused; previews remain private and uncached.

Retains native editable Divi service pages, publication receipts, per-article authors, blog publishing, Rank Math metadata and checksum-verified updates.

The ZIP contains only the Publisher plugin source. No credentials, client records or page graphics are included.

Install or update through WordPress Plugins or the existing Publisher update checker.
