# Publisher 0.6.5

Adds bounded mobile header-image, specification-table, back-to-top, social-toolbar and Divi navigation repairs. Each repair is rehearsed before installation, uses a state hash and backup, and is verified on the public page afterward. Failed public verification restores the prior rules. No arbitrary CSS, scripts, content edits or new permissions are accepted through the repair endpoint.

Retains the native Divi page workflow, approved-image integrity and scaled-image URL corrections, saved authors, metadata, Rank Math and checksum-verified updates. Existing editorial approval and publication requirements remain in place.

The layout endpoint advertises supported recipe names so Atlas will not send a new repair to an older integration. This release does not publish or approve any article or page wording.
